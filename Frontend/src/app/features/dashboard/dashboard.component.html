🎨 Custom CSS & Styling Guide

💡 Developer Documentation: We've created a comprehensive documentation file in the repository root: CUSTOM_CSS_GUIDE.md. Any developer or designer editing your portfolio stylesheet can use either that file or this interactive in-app guide!

🚀 Core Selectors Registry

Use these exact classes inside the Stylesheet Editor to target and override sections of your public page:

Component Selector Description
Navigation Bar .navbar Floating nav bar. Target .logo or .nav-links a to override links.
Hero Name .hero-title span Your full name gradient text span (e.g. "Mohammed Zaghloul").
Hero Role Title .hero-title-role Your professional title (e.g. "Full-Stack Software Engineer"). Supports hover scale effects.
Project Cards .project-card Interactive portfolio project cards. Supports shadow effects and transform scaling.
Frosted Cards .glass-card Premium frosted glass cards utilizing CSS backdrop-filters.

🎨 Design System CSS Variables

MZ Portfolio is powered by a high-grade dynamic design system. Override these variables inside a :root block to redefine themes instantly:

:root {{ '{' }} --bg: #080a10; /* Main Page Background */ --surface: #0f121d; /* Frosted Card Backdrops */ --surface2: #171b2c; /* Elevated Interactive Elements */ --border: rgba(255, 255, 255, 0.08); /* Faint Grid Borders */ --text: #ffffff; /* Solid Primary Text */ --accent: #6c63ff; /* Primary Cosmic Accent (Violet) */ --accent2: #a855f7; /* Secondary Cosmic Accent (Purple) */ {{ '}' }}
